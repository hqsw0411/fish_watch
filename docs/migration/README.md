## 归并规则

- 以运行目录的 API、预测与训练入口为基线。
- 合入部署目录的按月聚合、多年发布、恢复下载、数据验证、温差固定色标支持和东亚配置。
- 删除重复入口的需要来自内容比较：部署根目录 `fetch_effort_resumable.py` 与 `scripts/fetch_effort.py` 相同，只保留后者作为标准入口。原件仍在输入快照。
- 初始包中 22 个同路径文件内容相同；11 个同路径文件存在差异，逐项处理而非按目录日期覆盖。
- 不复制旧 `deployment-manifest.json`；它描述旧打包内容，清理后已不适用。新发布包重新生成校验清单。
- 原服务器自动同步脚本不自动安装。`ops/sync_release.py` 保留其显式入口，服务器专用 IP、账号路径和运行状态文件不进入新配置。
- 模型源码与权重分开；训练输出默认迁至忽略的 `model-artifacts/runs/`，可通过环境变量指定外部路径。

## 修复

1. 统一依赖入口，修复运行版依赖清单缺少 FastAPI/uvicorn。
2. 支持配置选择与受约束的发布指针；每个 API worker 固定一个发布版本。
3. API 默认禁止重建数据库索引。数据准备仍可以在独立发布目录显式建库。
4. 接上数据清单的区域上限和预计算温差色标。大数据发布仅读取所需的一到两个月；未准备固定色标的大型旧发布会明确拒绝该分析，不一次加载所有月份。
5. 代码打包明确包含 `.tsx`、`.geojson`、`.sbatch` 和模型 `.py`，排除数据及权重；缺少应用入口直接报错。
6. 训练报告不再重复写入固定的历史 R²/相关系数结论；指标与相关性由每次计算的结果字段提供。
